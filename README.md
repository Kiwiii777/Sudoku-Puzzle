# Sudoku Puzzle
By: Rayan Haque

This project utilizes recursion and various methods to form a Sudoku puzzle grid. The board is stored as a 2D array, and each value in the grid corresponds to its position in the 2D array. 

The program is a console program. To run the program, open the files in a compiler such as VScode and run main.

The Sudoku board is generated by going through each cell one by one in the 9 by 9 board, and using methods to verify and select a number that works in the cell. The program uses recursion to verify and select a number, which is a better alternative to manually searching by itself because of the chance that the board had a wrong value previously. In this case, the whole board would need to be generated again. Once the values are chosen, they are stored in their respective cell in the board, in the 2D array.
